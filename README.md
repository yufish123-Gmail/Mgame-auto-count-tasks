# 自动加次数任务

平台标识为 `Mgame`。

首次在 Windows 电脑上使用时，在项目目录打开 PowerShell，用已安装的 Python 建立环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

电脑需要已安装 ADB（Android SDK Platform Tools）和 Windows 简体中文 OCR。当前模板按 1080×2400 竖屏校准。

已有其他可用 Python 环境时，可以通过 `-Python` 指定解释器。2026 年 11 月 21 日本机回测复用了相邻 FCash 项目的环境，在本项目目录执行的命令如下。

```powershell
$python = (Resolve-Path '..\Mgame-FCash-auto-tasks\.venv\Scripts\python.exe').Path
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Python $python -Task all -Execute
```

双击启动器时会查找本项目 `.venv` 和系统 Python。使用上面的指定环境方式时，预览、续跑和返回命令也应带上 `-Python $python`。

## 手机怎么准备

1. 等Mgame任务重置。用数据线连接手机和电脑，解锁手机。若手机弹出 USB 调试授权，点「允许」。
2. 打开Mgame，点右下角「我的」。也可以直接停在「领币页 → 加次数」列表。
3. 在电脑上打开项目目录，双击 **自动加次数任务.cmd**。运行时让手机保持解锁，等电脑提示各阶段处理完毕或显示停止原因。

游戏计时中会暂时回到手机桌面，等程序自己切回Mgame。运行时不要手动操作手机。结束后到「领币页 → 加次数」核对进度和领币次数。

## 执行顺序

1. 浏览页面领奖励（3 秒）
2. 浏览好物（5 秒）
3. 浏览优惠活动（10 秒）
4. 玩游戏（60 秒，+3）
5. 小字写「浏览 10 秒」的闪电奖励
6. 小字写「玩 20 秒」的闪电奖励
7. 听小说（30 秒）
8. 看短剧（60 秒）

程序按Mgame当前显示的进度接着跑。某项已做完或暂未列出时，以窗口里的结算和跳过提示为准。

## Python 自动运行

安装依赖后，可直接由 Python 执行整个流程。Windows OCR 仍由程序调用本机 PowerShell。

```powershell
.\.venv\Scripts\python.exe .\coin_helper.py --execute --task all
```

单独续跑某项可改为 `--task promo`、`--task games` 或 `--task listen30`。`--serial` 可指定已授权真机。使用其他 Python 环境时，将命令中的解释器路径换成实际路径。

阶段执行遇到短暂切页、截图不可用、落地页未确认或次数无法读取时，程序会保存现场、自动返回主界面，并在当前阶段按手机实际进度重试。每个阶段本次执行最多尝试 3 次，前面已处理的阶段继续保留执行结果。恢复主界面失败或达到上限时，窗口和日志会给出停止原因。

游戏等待 62/22 秒、听书 32 秒、短剧 62 秒沿用当前规则。截图和日志写入耗时计入对应的浏览、游戏和媒体等待区间，减少计时之外的重复等待。播放计时结束时会再次确认前台页面。

## 中途停住

先记下窗口里的阶段、停止原因和运行记录路径。把手机恢复到Mgame「我的」或「加次数」，再双击运行。若卡在其他应用或插屏，等上一次运行停止后，在电脑 PowerShell 运行以下命令返回Mgame：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -ReturnMgame
```

加次数结束后，如需继续做游戏中心任务，可用下面的命令从当前页面进入「玩游戏」首页。程序会识别「游戏中心」链接，遇到桌面入口提示时点「不需要」。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -OpenGameCenter
```
